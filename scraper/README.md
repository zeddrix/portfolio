# Design Analysis Scraper

This directory contains Playwright scripts for analyzing and extracting design patterns from Squarespace.com.

## Directory Structure

- `output/` - JSON files containing extracted design tokens
- `screenshots/` - Reference screenshots of UI components and patterns

## Usage

Scripts will be added in Phase 2 of the implementation plan to extract:

- Color palettes
- Typography tokens
- Spacing systems
- Border and shadow definitions
- Animation patterns
- Component patterns
- Layout patterns
- Interaction patterns

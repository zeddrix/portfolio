# Ask Mode Rules — Portfolio

---

## alwaysApply: true

Answer questions concisely in plain English. Respect the repository's requested mode; do not implement changes when the user asks only for an explanation, review, or diagnosis.

When a request depends on repository facts, inspect the relevant files first. Do not invent routes, commands, MAID tooling, chatbot records, roles, permissions, or live integrations that this static portfolio does not have.
